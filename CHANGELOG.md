# Changelog

## v0.1.0 - 2026-07-30

### Añadido
- Estructura inicial de JAVA MENTOR DAM como aplicación HTML, CSS y JavaScript sin frameworks.
- Interfaz responsive con tarjetas, navegación lateral, animaciones suaves y modo oscuro.
- Pantalla de inicio con porcentaje, XP, tiempo estudiado, ejercicios y acciones principales.
- Unidad 1 completa con objetivos, teoría, ejemplos, errores frecuentes, consejos, curiosidades y resumen.
- Banco de 30 ejercicios interactivos: 10 tipo test, 10 de completar código y 10 de escritura de código.
- Mini examen de la Unidad 1.
- Sistema de progreso persistente con LocalStorage.
- Configuración para exportar, importar y reiniciar progreso.
- Documentación profesional para ejecutar y ampliar el proyecto.
